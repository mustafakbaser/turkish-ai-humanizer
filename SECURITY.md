# Güvenlik

Analiz aracı yalnızca Python standart kütüphanesini kullanır, ağa bağlanmaz ve dosya sistemine yalnızca kendisine verilen metni okumak için erişir.

Bir güvenlik açığı bulduysanız herkese açık bir issue açmak yerine GitHub'ın [özel güvenlik bildirimi](https://github.com/mustafakbaser/turkish-ai-humanizer/security/advisories/new) özelliğini kullanın. Bildirimlere en geç bir hafta içinde dönüş yapılır.

*To report a vulnerability, please use GitHub's private vulnerability reporting instead of opening a public issue.*
